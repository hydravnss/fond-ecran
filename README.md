# Fond d'écran

Extension SillyTavern pour mettre une **image derrière le chat**, comme dans Emochi : le portrait du personnage (ou une image que tu choisis) remplit l'écran, les messages restent lisibles par-dessus, et tu règles le flou.

## Utilisation

1. Extensions → **Fond d'écran**
2. Laisse **Activer** coché
3. Ouvre un chat : l'avatar du personnage devient le fond
4. Règle le **flou**, l'**assombrissement**, la **position** et le **zoom**
5. Pour une autre image (comme dans Emochi) : **Choisir une image**, puis éventuellement **Revenir à l'avatar**

Les curseurs s'appliquent à tous les chats. L'image personnalisée est enregistrée par personnage (ou par groupe).

Ferme complètement l'onglet SillyTavern et rouvre-le après l'installation ou une mise à jour.

**1.0.1** : le fond s'affiche vraiment derrière le chat (plus seulement dans l'aperçu des réglages).

## Installation

Depuis SillyTavern → Extensions → Installer une extension :

```
https://github.com/hydravnss/fond-ecran
```

Ou clone dans `data/<user>/extensions/fond-ecran`, puis recharge la page.
